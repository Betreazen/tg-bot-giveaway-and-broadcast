# Changelog

Все значимые изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [2.1.0] - 2026-07-01

### Добавлено
- 🚩 **Подозрительные аккаунты**: админ помечает пользователей (кнопка в меню,
  username вводится в любом виде — `@name`, ссылка `t.me/name`, просто `name`;
  regex отрезает префиксы). Помеченные аккаунты продолжают участвовать в
  розыгрышах, но **никогда не выигрывают** — при выборе победителей они
  исключаются из пула (розыгрыш остаётся случайным среди легитимных участников).
  Есть и снятие метки. Пользователю ничего не сообщается.
  - Флаг `users.is_suspicious` (миграция 0002).
  - В лист Users добавлена колонка «Suspicious», в Overview — счётчик.

## [2.0.0] - 2026-06-22

### Изменено (BREAKING)
- ⚙️ Вся конфигурация перенесена в единый `.env`; отдельный `config.json` удалён
  (`JOIN_URL`, лимиты рассылки, `SHEETS_SYNC_ENABLED` и пр. теперь в `.env`)
- ⏰ Отображаемое время жёстко зафиксировано на МСК (GMT+3) независимо от
  часового пояса сервера; параметр `TIMEZONE` убран
- 🗄 Схема БД управляется Alembic-миграциями вместо `create_all`

### Добавлено
- 🗄 Alembic-миграции: идемпотентная начальная миграция (безопасный накат на
  существующую БД без потери данных), авто-`upgrade` в `docker-entrypoint.sh`
- 🐳 Изоляция Docker: префиксы имён/томов/сети (`COMPOSE_PROJECT_NAME`), порты БД
  не публикуются на хост, non-root образ, лимиты памяти — не конфликтует с
  другими ботами на сервере
- 🔑 `REDIS_FSM_PREFIX` — изоляция FSM-ключей при общем Redis
- 🛡 Middleware проверки админа (мастера ранее не были защищены)
- 🧪 Набор тестов (pytest) + `requirements-dev.txt`; `DEPLOY.md`

### Исправлено
- 🐛 Гонка при параллельных `/start` от нового пользователя — атомарный upsert
  (`INSERT ... ON CONFLICT`) для users и participants
- 🐛 Массовая рассылка больше не удерживает открытую сессию БД (утечка пула)
- ⚡ Синхронизация Google Sheets вынесена в поток (не блокирует бота); убран N+1
  в сводной таблице
- 🐛 `get_user_count` через `COUNT()`; ротация логов; удалён мёртвый дубль
  обработчика `nav:main_menu`

## [1.1.0] - 2026-06-02

### Добавлено
- 🔐 Верификация пользователей при регистрации в розыгрыше (защита от ботов)
  - 5 кнопок со случайными цифрами (0–9), одна правильная
  - Случайное расположение правильной кнопки (перемешивание при каждой ошибке)
  - Максимум 3 попытки — после этого блокировка для текущего розыгрыша
  - Таймаут сессии верификации: 3 минуты
  - Счётчик ошибок сохраняется между сессиями (защита от перезапуска)
  - Блокировки снимаются при новом розыгрыше
  - Администраторы освобождены от верификации
- 💾 Redis-хелпер для прямого доступа к ключам (bot/services/redis_client.py)
- 🎮 FSM-состояние `VerificationStates.waiting_for_button`

### Изменено
- 🔄 Обработчик /start теперь направляет пользователей на верификацию вместо мгновенной регистрации
- 📝 Добавлены новые сообщения в messages.json для этапа верификации

## [1.0.0] - 2026-01-04

### Добавлено
- ✨ Полнофункциональная админ-панель на inline-кнопках
- 🎨 Мастер создания розыгрышей с выбором даты/времени
- 📸 Обязательное медиа для анонсов (фото/видео/GIF/документ)
- 🎲 Автоматический случайный выбор победителей
- 📣 Гибкая система анонсов (канал/ЛС/везде)
- 📬 Массовые рассылки с rate limiting и retry логикой
- 📊 Опциональная синхронизация с Google Sheets
- ⬅️ Полная навигация "Назад/Отмена/Главное меню"
- 🔒 Проверка подписки на канал перед участием
- 🌍 Поддержка timezone Europe/Moscow
- 🐳 Docker deployment с docker-compose
- 📝 Подробная документация (README, SETUP, CONTRIBUTING)

### Исправлено
- 🐛 Навигация "Назад" на всех этапах мастера создания
- 🐛 Форматирование дат с правильными переносами строк
- 🐛 Конфликты версий зависимостей (aiogram + pydantic)
- 🐛 Монтирование service_account.json в Docker

### Технические детали
- Python 3.12
- aiogram 3.x
- PostgreSQL 16+ с SQLAlchemy 2.0 (async)
- Redis для FSM состояний
- Полное покрытие inline-кнопками
- Отсутствие текстовых команд в админ-панели
