# Telegram Giveaway Bot

Профессиональный Telegram бот для проведения розыгрышей с полнофункциональной админ-панелью на inline-кнопках.

## 🎯 Возможности

### Для пользователей
- ✅ Участие в розыгрышах через команду `/start`
- 🔒 Автоматическая проверка подписки на канал
- 🔐 Верификация при регистрации (защита от ботов)
- 📊 Информация о текущих розыгрышах

### Для администраторов
- 🎨 Удобная админ-панель с inline-кнопками
- 📅 Создание розыгрышей с выбором даты/времени
- 📸 Обязательное медиа для анонсов (фото/видео/GIF/документ)
- 🎲 Автоматический случайный выбор победителей
- 📣 Гибкая система анонсов (канал/ЛС пользователей/везде)
- 📬 Массовые рассылки с rate limiting
- 📊 Опциональная синхронизация с Google Sheets
- ⬅️ Полная навигация "Назад/Отмена/Главное меню"

## 🛠 Технологический стек

- **Python**: 3.12
- **Telegram Framework**: aiogram 3.x
- **База данных**: PostgreSQL 16+
- **Кеш/FSM**: Redis
- **ORM**: SQLAlchemy 2.0 (async)
- **Деплой**: Docker + docker-compose

## 📋 Требования

- Docker и docker-compose
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- ID канала для проверки подписки
- ID администраторов

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/tg-bot-giveaway-and-broadcast.git
cd tg-bot-giveaway-and-broadcast
```

### 2. Настройка переменных окружения

Скопируйте файл примера и заполните своими данными:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# Получите токен у @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# ID администраторов (через запятую)
ADMIN_IDS=123456789,987654321

# ID канала (начинается с -100)
CHANNEL_ID=-1001234567890

# Остальные настройки можно оставить по умолчанию
```

**Как получить ID канала:**
1. Добавьте бота [@userinfobot](https://t.me/userinfobot) в свой канал
2. Перешлите любое сообщение из канала боту
3. Скопируйте ID (например: -1001234567890)

### 3. Настройка конфигурации бота

Скопируйте файл примера конфигурации:

```bash
cp bot/config/config.json.example bot/config/config.json
```

Отредактируйте `bot/config/config.json`:

```json
{
  "timezone": "Europe/Moscow",
  "join_url": "https://t.me/your_bot?start=join",
  "rate_limits": {
    "broadcast_rps": 20,
    "announce_rps": 20,
    "burst": 5,
    "max_retries": 5
  },
  "sheets_sync": {
    "enabled": false
  }
}
```

Замените `your_bot` на имя вашего бота.

### 4. Запуск бота

```bash
docker-compose up -d
```

Проверка логов:

```bash
docker-compose logs -f bot
```

Остановка бота:

```bash
docker-compose down
```

## 🎮 Использование

### Для пользователей

1. Отправьте `/start` боту
2. Подпишитесь на указанный канал (если еще не подписаны)
3. Пройдите верификацию: бот отправит сообщение с 5 кнопками — нажмите на указанное число
4. После успешной верификации вы участвуете в активном розыгрыше

> ⚠️ У вас есть 3 попытки для прохождения верификации. При 3 ошибках участие в текущем розыгрыше блокируется. Время на верификацию — 3 минуты.

### Для администраторов

1. Отправьте `/admin` боту в личных сообщениях
2. Используйте inline-кнопки для управления:
   - **Создать розыгрыш** - пошаговый мастер создания
   - **Анонсировать розыгрыш** - отправка анонса в канал/ЛС
   - **Завершить розыгрыш** - выбор и публикация победителей
   - **Рассылка** - массовая отправка сообщений
   - **Статус** - информация об активном розыгрыше

## 🔧 Дополнительные настройки

### Google Sheets синхронизация (опционально)

1. Создайте Service Account в Google Cloud Console
2. Скачайте `service_account.json`
3. Поместите файл в корень проекта
4. В `.env` добавьте:
   ```env
   GOOGLE_CREDENTIALS_PATH=/app/service_account.json
   SPREADSHEET_ID=your_spreadsheet_id
   ```
5. В `config.json` включите синхронизацию:
   ```json
   "sheets_sync": {
     "enabled": true
   }
   ```
6. В `docker-compose.yml` раскомментируйте строку:
   ```yaml
   - ./service_account.json:/app/service_account.json:ro
   ```

### Настройка rate limits

В `config.json` можно изменить скорость рассылок:

```json
"rate_limits": {
  "broadcast_rps": 20,    // сообщений в секунду при рассылке
  "announce_rps": 20,     // сообщений в секунду при анонсах
  "burst": 5,             // пиковая нагрузка
  "max_retries": 5        // количество повторов при ошибках
}
```

## 🐛 Решение проблем

### Бот не запускается

1. Проверьте логи: `docker-compose logs bot`
2. Убедитесь что `.env` заполнен корректно
3. Проверьте что PostgreSQL и Redis запущены: `docker-compose ps`

### Ошибка подключения к базе данных

Подождите 10-15 секунд после `docker-compose up` - база данных инициализируется.

### Кнопки не работают

Убедитесь что отправляете команды боту в **личных сообщениях**, а не в группах.

### Google Sheets не синхронизируется

1. Проверьте что `service_account.json` находится в корне проекта
2. Убедитесь что Service Account имеет доступ к таблице
3. В `config.json` установите `"enabled": true`

- ⚠️ **Никогда** не коммитьте `.env` и `service_account.json` в Git
- ⚠️ Храните `BOT_TOKEN` в секрете
- ⚠️ Регулярно обновляйте зависимости: `pip install -U -r requirements.txt`
